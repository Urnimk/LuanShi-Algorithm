亂世演算 V8_8 → V8_8_1 修改摘要
====================================
版本：亂世演算_V8_8_1_決策與UI效能修正版
修改類型：效能優化與既有 UI 功能補充；沿用底線版本，不升 V9。
完整逐行差異：亂世演算_V8_8_to_V8_8_1.diff

引擎
- ENGINE_VERSION、檔名與啟動器載入名稱統一為 V8_8_1。
- 每世界年建立國家→戰爭索引；新戰爭立即加入，成員更新同步，戰爭移除立即同步。所有 active_wars 的移除經索引同步函式處理。
- `_evaluate_prewar_mobilization()` 重用同一回合的 recent_attackers 集合，避免每次重複轉換；會變動的戰力、兵力、敵意與戰線值未跨行動快取，以免改變決策結果。
- 極速模式設定為零額外等待；原本世界年運行迴圈依運算耗時扣除等待，因此保持計算盡可能快。
- 關閉市場時略過每年重設空市場執行狀態的冗餘呼叫。價格、世界銀行及市場欄位仍保留，避免改變既有結果及 JSON 欄位。

啟動器與 UI
- 國家、聯盟 Treeview 以穩定 iid 增量新增、刪除、更新；排序只在順序真的變更時移動列。
- 國家／聯盟詳細、編年史、經驗與市場詳情只在所在分頁可見時重算；切入分頁當下刷新。
- `Live_Ranking.txt`、`game.log` 以 mtime_ns、ctime_ns、size、inode 快取；檔案指紋不變就沿用文字內容，排名/經驗文字也只在內容變更時更新。
- 速度選單新增 1、0.5、0.25、0.1、0.05 秒／年與極速模擬。UI 更新固定約每秒一次，與模擬速度分離。
- 編年史與市場頁面仍保留既有功能與資料呈現。

刻意保留
- 未改戰爭勝負公式、國家平衡、AI state/action 編號與數量、reward、政權／聯盟／人口規則。
- 未修改或刪除任何歷史紀錄、最高戰力／最高人口／排名／世代／政權交接等資料規則。
- 未變更 JSON schema、Q-table 保存格式或市場平衡。舊引擎沒有發現必須保留的 `v85_engine` 存檔相容名稱；V8_8_1 啟動器有處理作業系統下載檔名自動加括號的情況。
