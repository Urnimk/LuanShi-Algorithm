亂世演算 V8_8_2 聯盟信心與革命情誼版
============================================================

一、基底與啟動
本版直接修改使用者上傳的「亂世演算_V8_8_1_決策與UI效能修正版.rar」。
沒有採用 V9，也沒有帶入 V9 的主動邀請、新星招募、關注名單等功能。
因本次擴充信心玩法，另存為 V8_8_2，原始 V8_8_1 不覆寫。

1. 解壓完整資料夾。
2. 將原本 saves 資料夾的副本放進本版資料夾。
3. 使用 Python 3.12 或以上，執行：
   亂世演算_V8_8_2_聯盟信心與革命情誼版_啟動.py
4. 所有 .py 檔須放在同一資料夾。本版沒有新增第三方套件依賴。
   Windows Python 安裝須包含 Tkinter（官方一般安裝通常包含）。

V8_8_1 存檔直接讀取，不用轉檔。本版會追加信心狀態與聯盟年資資料。
存檔仍為既有 JSON 架構，但不是完全零欄位變動：
  國家：alliance_confidence
  聯盟快照：alliance_confidence_meta、alliance_details 內的 confidence_summary
  特定共存亡戰爭：confidence_defiance_year（節制重複訊息）
舊版向新版本相容已測；不保證退回舊版後，新信心資料仍能保留。

二、介面新增
聯盟詳細查詢 → 聯盟摘要：
  聯盟存在年數。
  聯盟排名：例如「第 3 / 21 名（普通聯盟，依總戰力）」。
  每國的信心、利益、信任、革命情誼、評估理由與目前決策。

聯盟成員明細：
  新增「入盟年資」與「聯盟信心」欄位。
  保留國家、排名、戰力、人口、士兵、狀態與雙擊國家查詢。
  加入水平捲軸，較窄視窗仍可看到新增欄位。
  摘要文字過長時，可雙擊該列展開完整文字。

排名口徑：普通聯盟依存活成員總戰力排名，同分以名稱排序；分母只計普通聯盟。
臨時反霸權聯軍另有自己的排名分母，避免同一國被普通盟與臨時聯軍重複計入同榜。
臨時聯軍顯示成立後年數與聯軍年資，但不套用普通盟的留盟信心。
原版臨時聯軍成員於成立時加入，後續只移除，不額外招募。

三、每國獨立的三項評估
每十個世界年評估一次，不同國家不共用同一個信心值。
新盟約初始信心60、信任55、革命情誼0；需要觀察才能累積可信的長期趨勢。
同年重複呼叫不重複結算，也不新增抽籤。

1. 自身利益（0～100）
依目前世界排名及相對盟友實力，動態區分弱國、中型國、強國、霸權國。
弱國較重視保護與成長；中型國重視保護與發展平衡；
強國／霸權國增加主導地位、自主發展及單向付出的考量。
相同聯盟中，小國與核心強國可能得到完全不同的分數。

觀察戰力、人口、糧木金屬庫存、盟內實際援助與付出、戰爭疲勞、
聯盟戰力趨勢、國際排名、盟內敵意、核心強國衰退及本國是否獨自作戰。
觀察窗最多七次評估；至少20年資料才使用成長／衰退趨勢。
戰力／人口以實際規模設分母下限，避免極小基數成長被高估。
資源庫存只是收益的代理，不宣稱等同生產力或完整戰爭損益會計。

戰爭頻繁本身不固定扣分。聯盟戰力持續成長、自身有實際收益可加分；
自身收益低且疲勞、衰退加劇，才扣除戰爭負擔。
弱國和平發展有額外利益；主力長期付出且發展停滯，會感受到成本。
強盟本身不是利益綁架，也不是背叛理由。

2. 對盟友的信任（0～100）
真實資源轉移、實際防守出兵、共同勝利與抵禦強敵，可以提高信任。
拒絕共同防禦、盟友滅亡、聯盟爭執、背叛等會降低信任。
已打滿戰線而無力支援，扣分較小，且不計入蓄意違約次數。
不能把投贊成票當作真正出兵；軍事支援以既有有效出兵貢獻的增量為證據。
資源援助只觀察已經發生的轉移，不額外生成資源。

3. 革命情誼（0～100）
真實共同作戰每國每世界年最多計一次；多戰線不重複灌年度情誼。
共同勝利、危機、被攻擊時獲得盟友出兵與資源支援，能累積情誼。
劣勢危機以戰前雙方兵力比較判斷，避免用勝利後的殘兵製造假危機。
共同作戰每年+0.35情誼、共同勝利+4、重大劣勢危機+5；
危機每國至少間隔20年才再計一次，資源援助加成依實際規模限制。
同盟年資本身最多補8分，而且必須已有共同作戰或實際援助經驗。
因此，光是同盟待得久，不會自動變成共存亡。
盟友背叛可大幅削弱信任與情誼；長期生存危機也能突破老交情的慣性。

四、信心慣性與共存亡
目標信心＝利益55%＋信任30%＋革命情誼15%。
一般每次評估只往目標靠近30%；高情誼時的下降速度降為16%。
信心沒有永久不墜的硬底線；利益低於25且信任低於30時，會繼續惡化。
短期敗仗不會立即退出，長期困境也不會被年資永久遮蔽。

共存亡須同時滿足：
  信心至少85、信任至少85、情誼至少75、利益至少65；
  至少2次共同重大危機，至少20個實際共同作戰年。
信任受背叛破壞時，即使上一輪有此意願，也會立即停止適用。
符合條件者可以拒絕本國的求和並繼續作戰；
國都陷落、空城失守、戰爭期限與既有勝敗判斷仍然有效。
共存亡不提供無敵，也不會把「拒絕求和」誤當成「求和被敵人拒絕」而當場滅國。
這是外交選擇，並未修改傷害、勝負或人口資源平衡公式。

五、離盟及背刺
一般和平退盟需全部符合：
  信心低於35，且連續至少3次評估不滿；
  入盟至少40年，至少已有20年的趨勢觀察；
  獨立／中立或其他有空位聯盟的預期價值，至少高於留盟8分；
  不在退盟冷卻期，且不處於極高認同的共存亡狀態。
符合後提出10年告知，期滿再評估。關係回升可以撤回。
共同戰事尚未結束通常延期，不讓一般不滿自動變成棄戰。
若利益<15、信任<20且持續至少6次低信心評估，允許重大存續危機例外。
離盟後30年內不能立刻重新入盟；原有申請結盟與新盟成立仍沿用原版。
其他聯盟只算「嘗試申請的預期」，有折扣，不假設議會必定收人。

Action 4背刺仍保留原編號及原後果，但需更嚴格的真實理由：
  先符合持續低信心與離盟利益條件；
  信任<25、至少2次嚴重失信紀錄、對現有盟友敵意至少70。
目標改為敵意最高的盟友，並記錄理由，不能隨機挑無辜盟友。
確認可以退出後才執行原版的掠糧及惡名後果，避免退出失敗卻先偷資源。
政治不穩、發生政變、單次爭執或盟友比自己強，都不能單獨觸發背刺。
政變與爭執的舊退盟呼叫也接上同一個守門條件。

移除原本「聯盟太強／核心太強就自動整盟瓦解」路徑。
理由：它直接繞過每國的利益、信任與革命情誼，與本次需求相衝突。
因死亡只剩不到兩國而解散，仍屬自然結束，另記清楚原因，不算無故退盟。

六、年資與舊存檔
新成立聯盟與新入盟，精確保存成立年與加入年。
舊檔若有 alliance_join_turn，直接使用；0年也視為合法年份，不誤換成現在。
舊檔若沒有成立年，以目前最早已知成員的加入年作「至少存在」的下限；
若連加入年也沒有，從首次觀察年起算下限，明確標示「至少／舊檔未記錄」。
不會虛構聯盟的真實成立年份。國家重生後不繼承前一世的盟約信心或加入年。

七、原因紀錄
saves/game.log：沿用原版最近1000行，供介面即時顯示。
saves/alliance_confidence_history.jsonl：新增只追加的因果紀錄，
保存信心變動、分項分數、主要因素、相關實際事件、退盟告知及最後決定。
舊game.log的容量機制不變，新因果檔不自動刪除。
每國 JSON 僅保留小型觀察窗與待結算事件，不把所有歷史重複塞進年度存檔。

八、驗證與限制
全部交付 Python 檔語法檢查通過。
19項情境測試通過，測試程式及實際結果在「驗證」資料夾。
涵蓋：個體差異、角色轉換、年資缺失與0年、戰時成長、實際支援、
不因年資直接共存亡、背叛破壞情誼、情誼慣性、長期危機突破慣性、
和平退出、告知撤回、戰時延期、JSON續跑一致與UI摘要／成員欄位等。

百國引擎測試：
  Seed882：新局0→1000年，53.989秒；無崩潰，100國存活、22聯盟、3戰爭。
  Seed883：新局0→500年，27.942秒；無崩潰，100國存活、21聯盟、6戰爭。
  V8_8_1產生的100年存檔→本版200年，4.231秒，無需轉檔。
  修正共存亡求和流程後，1000→1100年續跑通過，5.065秒。
  最後另做新局100年與舊檔續跑煙霧檢查；詳見驗證摘要。
這些是本環境運行時間，不是與原版公平比較的效能百分比。
兩組長跑同時執行，不應拿它們彼此比較速度。

自然模擬中尚未出現和平退盟或背刺；情境測試可以觸發。
目前門檻偏保守。沒有為了增加事件數而加入無理由抽籤。
Seed882第1000年出現8國符合共存亡意願，但這不等於8次實際拒絕求和。
最終信心原因與實際求和行為，應分別查看，不混稱驗證結果。

舊檔100筆既有編年史最高戰力紀錄在續跑後均仍存在，巔峰不倒退。
編年史函式、戰力公式、ExpectedSarsaLambdaPolicy 與狀態核心已做程式結構比對，保持原樣。
六個既有輔助 .py 模組與上傳版逐位元相同。
原生 Tk 視窗未做實機壓力測試：本環境沒有 DISPLAY／Xvfb。
已以介面替身執行真實 on_alliance_selected 方法，檢查新增列、欄位數、普通盟與聯軍分母。
仍需使用者在 Windows 實際觀察欄寬、滑鼠點選與長時間 GUI 流暢度。

九、這版刻意保留的界線
沒有移植V9、沒有主動招募新星、沒有重整Q-table，也沒有改SQLite。
沒有改傷害／勝負公式、Action編號、Q-state結構、Reward公式或市場平衡。
保留V8_8_1既有速度、UI增量更新、戰爭索引及檔案快取。
本版必然會因外交選擇不同而產生不同世界歷史，不宣稱與原版同Seed結果相同。

本次「利益」以這個版本已存在的戰力、人口、資源、排名與戰爭資料作代理。
此版沒有完整地圖領土、正式戰略目標、條約利益分配或未來生存率預測模型，
因此不把領土報酬、擴張受限、戰略目標衝突或存活機率宣稱為精確直接計算。
主導地位與自主性是依實力占比、單向援助及自身發展停滯作保守評估。
這些更細的直接證據適合後續在本版基礎擴充，不能用任意數值假裝已有資料。
