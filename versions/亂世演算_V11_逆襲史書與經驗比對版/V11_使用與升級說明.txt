亂世演算 V11｜逆襲史書與經驗比對版

【啟動與升級】
解壓縮後，以 Windows Python 執行「亂世演算_V11_逆襲史書與經驗比對版_啟動.py」。
建議複製整個 V10 的 saves 資料夾到本版旁，再啟動；保留原資料夾作為備份。
本包不含模擬用存檔，也不將實測示例寫入玩家的圖書館。
若您有自行改動的程式，請保留自己的版本；本版底稿是本次上傳的 V10 RAR。

【為什麼升 V11】
新增跨屆最多300年的有界觀測紀錄、完整決策帳、百年統計及兩道條件比對，
圖書館存檔格式由 schema 1 升為 schema 2。國家存檔與 Q 表狀態／行動結構不變，RL_VERSION 仍為9。
原排名公式、戰爭規則、拒和後國都淪陷直接滅亡、聯盟解散自動追蹤第一名及原 LOG 介面保留。
保留您上傳版的藏書100本、研習200年回顧、性格不顯示次傾向設定。

【三種書怎麼選】
1. 冠軍之路
每屆結算收錄實際冠軍，再區分：弱國逆襲、同起點競逐、霸權守成、中堅突破、觀測未完整。
弱國逆襲必須具備完整本屆起點與連續500年資料，起點排名並列百分位至少40%、
相對第一名戰力不高於60%，並通過下列成長條件。
全世界開局同戰力時，排行榜排列靠後不代表比較弱：並列實力用於篩選與AI比對。
藏書到達上限後，優先保留逆襲與復甦類案例，也保留其他類型的空間。

2. 成長與復甦紀
不再每100年就提前定稿；完整一屆500年後，最多選4國，弱起點優先，高起點最多1國。
條件：戰力至少增長80%且至少1000、人口至少增長20%、並列排名百分位提升至少15個百分點、
相對第一名戰力比例增加至少10個百分點、每人存糧不低於1，並且仍存續。
當曾發生持續衰退，後來恢復到觀測高峰的90%以上時，另標「衰退後復甦」。
當屆冠軍不再重複占用成長書名額。沒有合格案例就不湊數。

3. 興衰與覆亡
確認滅亡時：使用同一代國家覆亡前最多300年的紀錄，可跨賽季；每10年保留完整節點，
可能比300年略短，明列實際觀測起點，不回填未知年代。戰力高峰與衰退另由年度數據追蹤。
至少觀測5年，而且該窗內曾處於前半段或相對第一名戰力達35%以上，才列為優先衰亡案例。
屆末另選最多2個「仍存續但嚴重衰退」國家：屆初前半段或相對第一名至少35%，
有連續5年的戰力衰退警訊、屆末戰力不及高峰55%，且排名退步至少15個百分點，
或相對第一名戰力剩起點60%以下。
不同國家世代不相接；未觀察到的死亡不推定成軍事覆亡。

【每本書新增什麼】
適合誰讀、入選原因、觀測尺度、起訖排名（含分母）、同戰力並列位置、人口、士兵、
士兵比例、名義戰力、糧食與每人存糧、城防、疲勞、相對第一名實力。
完整行動嘗試總數／成功／失敗／改派次數；逐項行動帳與每100年的決策統計和精確節點對照。
單次行動後續案例只挑代表性紀錄，並非保存全部逐年決策。總量帳則保留完整統計。
年表、高峰與衰退、危機前和危機後的案例標示；外部支援未計量時，不假裝已證明政策因果。
士兵×50仍是排行榜名義戰力，不能把它當勝率；每人存糧也不是續航年數。

【AI怎麼讀】
第一道：把自身本屆觀測起點與書中起點比對，涵蓋並列排名、相對戰力、人口規模、
軍備、存糧、盟友、安全狀態。起點相似度至少0.78。
覆亡書的起點指覆亡前觀測窗起點，與完整賽季起點的定義不同；書中會標明。
第二道：比對決策當時的賽季階段、零／一／多線戰爭、保護、軍備、存糧、城防等，
當下相似度至少0.80。兩個分數都不是成功機率。
只參考先前已出版、已完成追蹤、目前合法的行動；相同案例不重複加權，最多3本來源。
只小幅加減策略選擇分數（每項不超過±0.18），不覆寫Q值、不抄兵力比例、保留探索。
決策案例先做15年後續觀測；研習採用依您的設定做200年回顧，滅亡或換代可提前中斷。
改善／惡化／無明顯改善都回寫經驗權重。這是同時期觀測，並未證明結果由某次研習造成。

【舊圖書館】
可讀 V10 schema 1。原書保留給玩家閱讀並標為舊版，缺少的新欄位不補造。
V11不把這些舊書放入新AI索引；原本缺少的完整決策帳與起點比對資料，從升級時重新觀察。
舊版尚在追蹤的圖書館案例及採用紀錄會結束，不偽造完整回顧；Q表與國家資料不重置。
若從屆中開始，冠軍書可刊行但明列不完整；成長／整屆衰退書須等下一個完整500年。
升級後圖書館寫成schema 2，不要再拿同一份圖書館存檔交給V10讀取；原版備份可獨立使用。

【怎麼讓人閱讀】
遊戲左側「世界圖書館」可搜尋國家、書名或案例類型，選書後直接閱讀，字級可調。
匯出本書／全部 HTML 可離線開啟，附數據比較表、完整正文、年表、研習回顧，亦可列印PDF。
實測閱讀示例在「閱讀示例」資料夾；它只供人閱讀，不注入玩家世界或AI。

【空間與驗證】
最多100本：冠軍40、成長28、興亡32；最多200個國家觀測槽。
每國最多32個完整歷史節點、301筆年度高峰判定資料、300年的聚合行動帳、24則代表性完成案例。
單本最多6個決策案例；最近200則研習／回顧。圖書館每10年保存，重要結算即保存。
重要轉折的年表為抽樣，精確百年節點另保存；不聲稱保存每件歷史事件。
完整驗證結果見「驗證」資料夾；不以少量模擬宣稱AI必然變強。
此環境無Windows桌面，未實際點擊Windows版Tk視窗；已做介面替身、自動測試及實際引擎模擬。

【V11追加修正：聯盟信心紀錄】
alliance_confidence_history.jsonl 只保留目前年及之前999年，共1000個年份。
啟動時串流清理既有大檔，之後每年檢查過期紀錄；無新事件也會清理。
不另存舊紀錄、不建立長期摘要；無法辨識年份或不完整的紀錄行會移除。
回讀較早存檔時，超出目前年份的歷史亦會移除。
只調整歷史文字檔保存，不改信心數值、革命情誼、退盟判斷、Q表或世界圖書館。
已存在的大檔首次清理需等待磁碟讀寫；採逐行處理，不將整份大檔載入記憶體。
