亂世演算 V8_4_6｜賽季爭冠學習版
========================================

一、本次實測結果
------------------
1. 樣本已執行至第 3 屆、約 Turn 3,600，累積約 27,040 個 Q-State。
2. 戰力 Gini 為 0.428，並非戰力過於平均；國家強弱差距已相當明顯。
3. 財富 Gini 為 0.674，貧富差距比戰力差距更大。
4. 實際第一主傾向分布：
   - 征服擴張型：47 國
   - 外交聯盟型：39 國
   - 經濟建設型：7 國
   - 財政人口型：3 國
   - 背叛機會型：3 國
   - 防禦休養型：1 國
5. 原版顯示大量「混合型」的主因，是把未嘗試行動的 Q=0 也列入人格排名，
   加上固定 0.08 差距門檻過寬，不完全代表國家真的沒有偏好。
6. 行動使用並不均衡：反霸權圍剿僅 2 次，結盟 1,247 次且成功率約 37.3%；
   此次先不人為強迫各類行動平分，避免把「看起來多樣」誤當成「真正學會」。

二、人格反推修正
------------------
1. 人格仍然 100% 由各國自己的戰略 Q 值反推，沒有預設好戰、和平或經濟人格。
2. 未達最低嘗試數的 Action 不再參與人格排名。
3. 改比較每個 State 內的相對 Q 優勢，降低難易度不同狀態互相稀釋的問題。
4. 國家資訊會優先顯示明確主型，只在前兩名 Q 傾向真的非常接近時，
   附註「次傾向」，不再大量統稱混合型。

三、賽季爭冠學習
------------------
1. 原版屆末只記錄冠軍，沒有把冠軍結果回饋 Q-table；AI 並不知道第一名是最終目標。
2. 新版每 100 Turn 進行屆中檢查：
   - 名次上升：小額正獎勵。
   - 名次下降：小額負獎勵。
   - 當下第一、前三、前十名有递減的站位獎勵。
3. 屆末終局 Q 獎勵：
   - 冠軍：+6.0（最高）
   - 亞軍：+2.5
   - 季軍：+1.5
   - 第 4～10 名：+0.8 至 +0.2
   - 第 11～25 名：+0.1
   - 其餘名次：依後段百分位給予小額負獎勵。
   - 屆末已滅亡：至少 -1.5。
4. 終局獎勵會回寫最近戰略決策，並透過 Expected SARSA(λ) 的資格跡影響近期決策。
5. 冠軍獎勵寫入後會立即儲存 Q-table，避免結算後突然關閉造成學習結果遺失。

四、0.1 秒一回合的判斷
------------------
1. 0.1 秒是模擬排程速度，不會直接改變 Reward 公式、Q 值更新式或 Action 機率。
2. 實際 Turn 數不會等於秒數÷10，因為市場、戰爭、存檔、UI 更新與日誌都會佔用時間。
3. 本次樣本約 3,600 Turn，可用於找出明顯架構問題；人格長期分化與冠軍學習仍建議再跑 5～10 屆觀察。

五、相容性與使用
------------------
1. 本次沒有改變 State 維度與 Action 數量，因此 RL_VERSION 維持 6。
2. 可直接延續使用 V8_4_5 的 saves 與 rl_agents_q_tables.json，不需清除學習資料。
3. 依既定規則，程式的讀取與產生檔案均使用 saves 資料夾，不存在時會自動建立。

六、建議下次觀察指標
------------------
1. 5～10 屆後，各主型人格的國家數量。
2. 同一國家的人格主型是否連續 2 屆以上穩定。
3. 歷屆冠軍是否來自不同策略，還是全部被征服擴張型壟斷。
4. 第 1～3 名的平均戰力差，是否因爭冠訊號而縮小。
5. 反霸權圍剿 Action 是否仍接近零；若仍然過少，應另案調整圍剿候選門檻與可用性，
   不建議只用虛假 Reward 強迫出現。
