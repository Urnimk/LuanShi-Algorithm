《亂世演算》V6.4｜戰力權重投票版

【核心規則】
普通聯盟的正式議會表決改成：

票權 = 國家當下戰力

例如：
A國戰力 1,000,000 → 票權 1,000,000
B國戰力   100,000 → 票權   100,000

因此 A 國的議會影響力正好是 B 國的 10 倍。

【適用範圍】
1. 聯盟主動開戰表決
2. 新國家申請入盟表決

共同防禦目前不是「全聯盟多數決」：
被攻擊國一定自衛，其他盟國各自決定是否派兵，
因此不套用集體戰力加權門檻。

【通過方式】
以所有合格投票盟員的總戰力作為 100% 票權。

過半門檻：
total_weight // 2 + 1

只有「贊成票」的戰力權重會累加到 yes_weight。
反對與棄權都不算贊成，但仍包含在全體總票權內。

因此必須取得「全體合格戰力票權嚴格過半」。

【例 1：一個大國可以壓過四個小國】
大國：1,000,000，贊成
四個小國：各 100,000，全部反對

總票權 = 1,400,000
過半門檻 = 700,001
贊成戰力 = 1,000,000

結果：通過

雖然人頭是 1 贊成、4 反對，
但大國戰力占聯盟約 71.4%，因此議案通過。

【例 2：四個小國也可能被一個超級大國否決】
大國：1,000,000，反對
四個小國：各 100,000，全部贊成

總票權 = 1,400,000
過半門檻 = 700,001
贊成戰力 = 400,000

結果：否決

【零戰力特殊處理】
若聯盟所有合格成員的戰力剛好全部為 0，
才暫時退回「每國 1 票」，
避免總票權 0 導致永遠無法做決議。

最近議會表決會改顯示：

詳細 Log 會同時顯示：
- 每國投贊成 / 反對 / 棄權
- 每國實際票權

- 過半門檻
