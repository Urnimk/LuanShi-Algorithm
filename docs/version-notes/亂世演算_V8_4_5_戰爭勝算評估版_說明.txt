亂世演算 V8_4_5｜戰爭勝算評估版說明
====================================

【版本性質】
本次屬於小版本更新：V8_4_4 → V8_4_5。存檔與既有多層 Q-Table 可繼續使用。

【一、宣戰前完整陣營估算】
1. 不再只比較進攻國與目標國的個別戰力。
2. 估算包含攻守雙方普通聯盟成員；盟友依預估參戰率折算。
3. 每個國家的有效戰力會考慮：
   - 糧食、金屬與木材補給。
   - 戰爭疲勞。
   - 已有戰線與第二戰線折損。
   - 防守方城防加成。
4. 介面顯示最近目標、勝算、有效戰力比與撤回次數。

【二、宣戰勝算門檻】
1. 一般戰爭估計勝算至少 35% 才能宣戰。
2. 復仇、敵意達 80 或反霸權圍剿，可放寬至 20%。
3. 低於 20% 的近乎自殺式戰爭一律取消。
4. 若所有目標都不合理，AI 會記錄最佳目標與取消原因，並以失敗經驗更新 Q 值。

【三、目標選擇改善】
1. 保留敵意、復仇、資源價值、肥羊與事件目標等既有因素。
2. 新增完整陣營勝算分數；勝算高於 50%會加分，低於 50%會產生負分。
3. 敵國個體雖弱、但背後聯盟龐大時，不會再被誤判成容易攻擊的肥羊。
4. 15%的隨機目標也只能從通過最低勝算門檻的國家中選取。

【四、盟友表決後再次評估】
1. 宣戰提案與共同防禦表態完成後，以真正參戰名單重新計算勝算。
2. 若進攻盟友拒絕參戰，導致勝算跌破門檻，發起國會理性撤回宣戰。
3. 撤回同樣會回饋 RL，避免直接跳過造成 AI 學不到教訓。

【五、戰爭 Reward 修正】
1. 成功建立戰爭不再額外取得大量 Reward，只保留極小的行動回饋。
2. 已有戰爭又開第二戰線，立即受到額外扣分。
3. 8 回合後依真正戰果評估：
   - 戰勝：+12。
   - 戰敗：-14。
   - 攻陷首都：+20。
   - 低勝算下以弱勝強：追加獎勵。

【六、修正 Action 0 延遲學習錯誤】
舊程式以「engine_action or 3」讀取動作編號；Action 0 會被當成 False，因而誤判為 Action 3。
本版已改成保留數值 0，戰勝與戰敗的延遲結果現在會正確更新戰爭策略 Q 值。

【測試結果】
1. 單國 1,200 戰力攻擊 700 戰力孤立國：估計勝算 63.2%。
2. 同一目標獲 1,600、1,400 戰力盟友支援後：攻方估計勝算降為 24.6%，會被一般戰爭門檻阻止。
3. 補給不足與第二戰線會依序降低有效戰力。
4. 戰敗延遲 Reward 測試為 -14，已確認正確回到 Action 0。
5. 固定種子 30 國、150 回合整合測試完成：29 國產生戰爭評估紀錄，戰爭仍可正常成立與結算，低勝算宣戰可被撤回。
