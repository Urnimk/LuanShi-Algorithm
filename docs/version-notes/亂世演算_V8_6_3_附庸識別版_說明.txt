亂世演算 V8_6_3｜附庸識別版

【本次小版本改動】

- 國家總覽以「◇」標示仍在期限內的附庸國。
- 國家總覽以「♛」標示目前擁有附庸的宗主國。
- 附庸國狀態直接顯示宗主國與剩餘附庸年數。
- 宗主國狀態顯示目前附庸國數量。
- 國家詳細資訊新增「附庸關係」：附庸國可查宗主國、宗主聯盟及剩餘年數；宗主國可查完整附庸名單。
- 聯盟成員表同步顯示上述代號與關係。
- 加入代號後仍可正常點擊或雙擊國名跳轉詳細資料。
- 只改UI顯示，不改戰鬥、AI、State、Action、Q值及附庸規則。

代號：◇＝附庸國；♛＝宗主國。

目的：新國家脫保後仍可能戰敗，但不再輕易因第一次重大失敗就直接從世界消失。
本版不新增 State 或 Action，屬 V8_6 的小版本實驗。

一、脫保前自主準備
- 保護期最後 50 年，每年保證取得一次主決策機會。
- 系統只把國家加入當年決策名單，實際行動仍由安全態勢 Q 值自行選擇。
- 保護期內仍禁止主動宣戰、背刺、襲擾與號召圍剿。

二、脫保後 50 年的國際反彈
- 剛脫保國家仍可被攻擊，不延長無敵期。
- AI 選擇攻擊目標時，會降低剛脫保國家的目標分數。
- 若仍正式宣戰，攻擊者承受：惡名 +18、國際忌憚 +6,000、政治穩定 -6。
- 過渡期越接近結束，目標分數減免逐步降低。

三、小國本土防禦
- 當攻方兵力遠高於守方時，守方取得地形、短補給線、守城與游擊加成。
- 兵力相近時沒有額外加成。
- 極端兵力差最高 35%，強國仍能取勝，但代價不再近乎為零。
- 宣戰前勝算評估與實際持續會戰都會計入這項加成。

四、戰敗分層
- 第一次國都陷落：不滅國，改為附庸臣服。
- 割讓現有糧食、木材、金屬各 12% 給主要勝方。
- 附庸關係持續 150 年，並取得 40 年戰後重整期。
- 重整期不能成為全面戰爭或襲擾目標，但仍可自行生產、施政、備戰與外交。
- 已有一次附庸紀錄的政權再次國都陷落：才執行原本完整滅國結算。
- 滅國後若依既有規則重建，附庸紀錄重新開始。

五、修正宣戰第一年屠殺
- 舊程式在守方 0 兵時，宣戰第一波可能直接按攻方兵力殺害農夫。
- 新版 0 守軍時不再於首輪直接屠殺平民，改交由攻城及主權結算處理。
- 有守軍的會戰即使傷害溢出，也至少保留 1 名平民，避免繞過附庸階段直接人口歸零。

六、可調參數
PRE_RELEASE_GUARANTEED_ACTION_YEARS = 50
POST_PROTECTION_TRANSITION_YEARS = 50
POST_PROTECTION_TARGET_SCORE_PENALTY = 45.0
POST_PROTECTION_ATTACK_INFAMY = 18
POST_PROTECTION_ATTACK_DREAD = 6000
POST_PROTECTION_ATTACK_STABILITY_LOSS = 6.0
HOMELAND_DEFENSE_BONUS_MAX = 0.35
SUBJUGATION_BEFORE_ANNEXATION = 1
VASSAL_DURATION_YEARS = 150
CAPITULATION_PROTECTION_YEARS = 40
VASSAL_REPARATION_RATE = 0.12

七、測試
- 第一次國都陷落：轉為附庸且國家仍存活，通過。
- 第二次國都陷落：執行滅國，通過。
- 40 年戰後重整保護判定，通過。
- 本土防禦加成 0%～35% 上下限，通過。
- 100 國固定 Seed 長期整合測試跑至 1,000 年：程式無例外、人口守恆通過、資源無負數。
- 第 1,000 年快照中 35 國曾被附庸，14 國仍在附庸期；測試期間仍有再次失守而滅國的案例，證明並非永久免死。

觀察重點：
1. 新國脫保後 50 年存活率。
2. 附庸國能否在 40 年重整期恢復軍備與城防。
3. 附庸是否太多、太久，必要時優先調整 VASSAL_DURATION_YEARS。
4. 若滅國變得過少，可把 SUBJUGATION_BEFORE_ANNEXATION 改為 0；若仍太殘酷可改為 2。
