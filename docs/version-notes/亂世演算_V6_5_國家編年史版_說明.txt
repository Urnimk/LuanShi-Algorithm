《亂世演算》V6.5｜國家編年史版

一、世界時間
- 正式採用「1 Game Loop = 1 年」的顯示概念。
- UI 國家編年史頁會顯示「世界曆：第 X 年」。
- 國家詳細頁會顯示「本政權存續 X 年」。

二、右側新增「📜 國家編年史」分頁
原本右側即時世界排名與 LOG 保留在「🌍 即時戰局」分頁。
新增獨立「📜 國家編年史」分頁，可選擇每一個國家查閱歷代資料。

三、編年史欄位
1. 國家世代
2. 國名
3. 政權類型
4. 建立年份
5. 結束年份
6. 維持年數
7. 結束原因（兇手）
8. 最高戰力（並顯示戰力巔峰年份）
9. 最高人口
10. 最佳排名

四、世代結束原因
- 正統交接
- 合法交接
- 軍事政變
- 民變革命
- 宮廷政變
- 滅國

若為滅國，會額外記錄實際擊潰該國的主要敵國，例如：
被【挫蛋軍政府II】滅國

五、編年史與 V6.3 三軌世代的關係
「國家世代」仍依 V6.3/V6.4 規則持續累加：
- 正統／合法交接：國家世代 +1
- 政變：國家世代 +1
- 亡國重建：國家世代 +1

國名 Roman 與括號世系仍採原有三軌規則，不受本版影響。

六、歷史統計
每一個世代持續記錄：
- 該世代最高戰力
- 最高戰力發生年份
- 該世代最高人口
- 該世代最佳世界排名

現行世代的結束年份顯示「現行」，維持年數會隨世界年份自動增加。

七、舊存檔相容
舊 V6.4 存檔沒有完整 country_chronicle。
V6.5 載入時會嘗試利用 regime_history 重建最近可辨識的政權更替歷史。
因舊版並未保存所有歷代最高戰力、最高人口及滅國兇手，因此：
- 無法確認的舊資料顯示「—」
- 最早建立年份無法確認時顯示「舊檔未知」
V6.5 啟動後的新歷史會完整記錄。

八、原有設定完整保留
- REGIME_CHANGE_COOLDOWN_TURNS = 90
- SUCCESSION_MIN_TENURE = 5000
- SUCCESSION_CHANCE_PER_COUNTRY = 0.1
- 戰力權重投票
- 入盟投票
- 聯盟開戰投票
- 共同防禦
- V6.3 三軌世代
- 斷點續跑
- 世界局勢
- 動態事件／政變
- 反霸權聯軍
- Q-table
