亂世演算 V8_4_9 自主決策修正版

這版直接以您上傳的 V8_4_8 戰爭經濟重整版為基礎，只移植《結構重構》文件中與決策相關、可以局部落地的核心精神：七項分析先提供連續訊號，最終 Action 仍由既有 Expected SARSA(λ) 的 Q 值和合法動作限制決定。

實際修改
1. 新增獨立的「亂世演算_V8_4_9_決策分析.py」。經濟、軍事、外交、人口、內政、外部情報、長期戰略七項分析均為只讀，輸出 0～1 的報告，不直接修改國家資料或執行動作。
2. 國家決策中樞只把分析報告收斂到原本的「戰前風險／動員需求」兩個 State 維度，不增加 Q-table 維數，也不改 Action 編號。
3. 移除「高戰前風險擲骰就動員」及「農夫對士兵達 4.5 倍就強制動員」的捷徑。風險仍會被觀察，Q 值可以選擇動員，也可以選擇其他可執行策略。
4. 啟動器改為載入本版引擎並更新視窗名稱；舊 UI 的布局、頁籤和其餘行為維持原樣。

維持原樣
存檔 JSON 與 Q-table 格式、RL_VERSION=6、16 個引擎 Action、原來的戰略／市場／聯盟學習子策略、世界銀行、市場掛單、同盟、戰爭、人口政策、資源公式、UI 排版及 saves 資料夾路徑均未改動。沒有把整個 V8 改寫成 V9，也沒有承諾《結構重構》文件列出的七層架構已全面完成。

安裝與啟動
將本套件內三支 Python 程式放在同一目錄，執行：
  python 亂世演算_V8_4_9_自主決策修正版_啟動.py
保留您現有目錄的 saves，可接續原 V8_4_8 存檔；請先自行備份 saves 再讓新版寫入舊進度。這個壓縮檔不附測試產生的 saves。

驗證
