戰國模式 V2・全面優化版
========================

這版以你上傳的「平衡防 OOM」引擎與「版面優化／等寬奪冠」UI 為底，不重做世界資料格式，舊存檔可續跑。

一、戰爭與外交
- 戰爭期限屆滿不再一律和局；依剩餘兵力、對手損耗、城防判勝負，真正接近才算和。
- 新增 wars_drawn 和局統計；UI 顯示勝／敗／和／戰中。
- 戰敗求和會支付少量糧／木／金賠款，資源只搬移、不憑空生成。
- 戰後 4 回合休戰，避免同一對國家立刻重開戰。
- 修正讀檔時「反霸權聯軍被同時誤當普通聯盟」的問題。
- 亡國後會退出舊普通聯盟；新世代重生必須重新外交。
- 主動全面宣戰需要基本軍力（至少人口 10% 或 12 名士兵），弱國仍可能被當肥羊攻擊。

二、AI / RL / OOM
- 移除未實際使用的 NumPy。
- RL 行動前後改成「輕量狀態快照」，不再 deepcopy 整份國家歷史資料。
- 每國 Q-State 仍維持 1200 上限；淘汰時優先刪除幾乎沒有資訊量的 Q-State。
- 探索率由 0.22 緩慢下降，最低保留 0.07。
- Q-table 仍每 10 回合保存，超大舊 Q-table 仍有 80MB 保護。
- Full GC 由每 2 秒改成每 30 回合，降低卡頓。

三、I/O 與長跑穩定性
- game.log 不再每印一行就重寫整個 1000 行檔案；改批次落盤。
- 排行榜、國家 JSON、聯盟 JSON 改成 temp + os.replace 原子替換。
- Live JSON 改緊湊格式，降低硬碟與記憶體壓力。
- 世界存檔失敗不再完全靜默，會留下警告。
- 保留歷史最高戰力／國家／屆次與本屆已跑時間，重啟後不歸零。

四、經濟／人口
- 全球正面事件機率由每輪 15% 降為 5%，避免金礦／大航海事件長局過度灌資源。
- 舊存檔若軍備目標曾被早期版本永久卡在 15% 左右，會一次性遷移回 30%。
- 重生軍備目標統一回 30%。
- 人口 LOG 改為：
  [持續戰爭]【國名】人口 A → B（守方會戰傷亡 -X；出生 +Y；淨增 -Z）。

五、UI
- 預設視窗改 1500×900。
- 聯盟成員表：國家欄吸收剩餘寬度，其他數值欄固定，不再右側留白。
- 國家戰績顯示勝／敗／和／戰中。
- 國家基本資訊新增 AI 性格、惡名／探索率。
- 世界總覽「狀態」會顯示戰中。
- 國家同時兩場戰爭時，第二場標示「第二線」。
- 反霸權聯軍摘要同時保留「目前狀態」與「討伐目標」。
- 冠軍紀錄把 R3__25000__國名 格式轉成「第 3 屆｜戰力 25,000｜國名」。

六、額外戰略平衡
- 正式戰爭每個持續回合都會消耗基本軍糧與金屬；第二戰線仍另外支付額外補給，長期戰爭不再只付首戰成本。
- 補給不足會留下「前線補給危機」LOG，後續經濟系統會因此縮編／影響續戰能力。
- 普通聯盟不再在單一成員只占全球 8% 時立刻瓦解，門檻提高到 12%，聯盟有更大機會形成陣營戰。
- 申請加入現有普通聯盟不再 100% 成功；惡名越高越可能遭拒。
- 世界排名所有名次都會顯示「⚔戰中」，不再只有第一名看得到。
- UI 國家／聯盟總覽與全域 LOG 加入內容快取：資料沒有變就不整張刪除重畫，降低閃爍與 CPU 使用。
