《亂世演算》V8_2｜穩定市場版

本版以 V8 世界市場版為基礎，重點是讓經濟、AI、存檔與操作具備可稽核性。

一、世界銀行與貨幣守恆
1. 每輪及存檔前核對：累計發行 = 各國金幣總和 + 世界銀行庫存。
2. UI 顯示流通量、銀行庫存、累計發行、累計回流及守恆差額。
3. 新增逆週期流動性回流：每 10 輪檢查一次；銀行保留 360 金幣重建準備金後，最多釋出庫存的 20%，優先支援人均金幣低於 3 的存活國家，每國單次最多 60 金幣。
4. 回流只動用銀行既有庫存，不增加 issued_total，也不干預商品價格。
5. 重建援助仍優先使用銀行庫存；不足部分才新增發行。

二、世界市場
1. 買單依其他掛單計算保留金幣；賣單依其他掛單保留物資，避免超額承諾。
2. 同一國、同一商品、同一方向只保留最新委託；買賣單可並存，但禁止自我成交。
3. 撮合採價格優先、時間優先，成交價使用較早委託者（maker）的價格。
4. 每次報價相對最近成交價限制於正負 20%。
5. 1% 手續費採無條件進位，最低 1 金幣，全部進入世界銀行庫存。
6. 新增近 10 筆成交量加權均價、掛單數、完整成交數、到期數及成交率。

三、自主學習 AI V5
1. 保留 16 Actions／11 維 State 與無固定人格設計。
2. Q-Learning 的下一狀態估值只使用下一狀態可執行的 Action，排除無效行動造成的虛高 Q 值。
3. 鼓勵生育、增產補貼、戰爭、外交金援及聯盟援助加入跨回合延遲成果評估。
4. 資產 Reward 改採世界市場近 10 筆移動均價；無成交才使用種子價格。
5. 保存 State 造訪次數、各 Action 累計次數／Reward／成功次數及待結算決策。
6. RL_VERSION 升為 5，不相容舊 Q-table 會重新學習，世界存檔不受影響。

四、存檔與重現
1. 國家與聯盟存檔加入共同 snapshot_id；讀檔時必須配對一致。
2. 每次寫檔自動保留 .bak；主檔不一致時選用最新的一致備份組合。
3. 找不到一致存檔時停止引擎，不建立新局、不覆寫原檔。
4. 新局自動產生 Seed；也可先設定環境變數「亂世演算_SEED」指定 Seed。
5. 存檔保存 Python 隨機狀態，斷點續跑可延續同一亂數序列。
6. 測試環境可用「亂世演算_MAX_TURNS」「亂世演算_LOOP_DELAY」「亂世演算_COUNTRIES」限制輪數、延遲與國家數量。

五、操作介面
1. 新增暫停／繼續、單步執行與 0.1、0.5、1、2、5 秒速度切換。
2. 世界市場顯示貨幣稽核、累計回流、Seed、近 10 筆均價及市場品質統計。
3. 國家詳細資訊顯示 AI 決策次數及最近延遲獎勵。

六、檔案
- 亂世演算_V8_2_穩定市場版.py：核心引擎。
- 亂世演算_V8_2_啟動.py：圖形介面啟動程式。
- test_亂世演算_V8_2.py：貨幣、市場、RL 遮罩及存檔復原自動測試。

啟動方式：
python 亂世演算_V8_2_啟動.py

執行測試：
python -m unittest -v test_亂世演算_V8_2.py
