亂世演算 V8_4_3｜基建與產業配置版說明
========================================

【版本性質】
本次屬於小版本更新：V8_4_2 → V8_4_3。存檔仍統一使用 saves 資料夾，舊存檔可繼續載入。

【Action 3：基礎建設投資】
1. 移除直接增加糧食、木材與金屬的「經濟發展」。
2. 國家必須實際支付金幣、木材及金屬，才能提升基礎建設。
3. 基礎建設上限 100，每次成功投資增加 3～6 點。
4. 成本隨基建等級提高：
   0～19：金幣 60,000、木材 50、金屬 20。
   20～39：金幣 80,000、木材 65、金屬 30。
   40～59：金幣 100,000、木材 80、金屬 40。
   60～79：金幣 120,000、木材 95、金屬 50。
   80～99：金幣 140,000、木材 110、金屬 60。
5. 支付的金幣進入世界銀行，不會憑空消失或新增貨幣。
6. 基建提高正式農民產能，最高提升 50%，也會提高市場掛單容量。
7. 資產不足或基建滿級時，Action Mask 不允許選擇此行動。

【Action 7：調整產業配置】
1. 移除以木材直接換糧食的「農業振興」。
2. 行動本身不增加、不扣除，也不轉換任何資源。
3. AI 比較糧、木、金屬的庫存需求比，優先配置最缺少的資源。
4. 可採糧食優先、木材優先、金屬優先或均衡生產。
5. 配置維持 8 年；資源只在正式經濟回合由既有農民產生。
6. 發生糧荒時，緊急糧食配置優先於一般產業配置。

【介面調整】
1. 第一列改為「房屋 / 基礎建設」。
2. 房屋資料右側顯示基建，例如「151 間 / 容量 1,510｜42/100」。
3. 新增「產業配置」列，顯示目前方向及剩餘年數。

【強化學習與相容性】
1. 戰略 Action 數量不變，既有 Q-Table 不需重建。
2. Action 3 Reward 依實際基建增幅計算；資金危機或被圍攻時盲目投資會扣分。
3. Action 7 選中缺糧配置時，會依糧食危機取得合理獎勵。
4. 舊存檔缺少的新欄位會自動補為基建 0、自動產業配置。
