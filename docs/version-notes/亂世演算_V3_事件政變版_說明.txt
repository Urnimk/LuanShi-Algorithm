戰國模式 V3｜事件・政變版

【新增核心】
1. 動態事件：邊境爭議、聯盟峰會、外交醜聞、軍備競賽、邊境集結、戰爭疲勞、商路繁榮、金屬短缺、豐收、王位危機、民族團結、戰爭英雄、聯盟爭執、共同防禦協議、天下震動。
2. 政治穩定度 0~100：戰爭、飢荒、疲勞會降低；和平、勝利、峰會等可提高。
3. 戰爭疲勞 0~100：每個持續戰爭回合增加，第二戰線增加更多；和平會逐步恢復。
4. 動態戰略模式：正常發展、糧荒求生、戰後復甦、全面防禦、戰時動員、報復模式、擴張模式、霸權維持。
5. 低機率政權更替：正統繼承、宮廷政變、軍事政變、民變革命。
6. 政變不建立新國家：dictionary key / 國家本體 ID 永遠不變，歷史戰績、奪冠紀錄等保留。
7. 政變若改國號，新名稱前兩個字一定取自原始 country key 前兩字。
   例：挫蛋先鋒 -> 挫蛋軍政府 / 挫蛋王朝 / 挫蛋共和國。
8. 正統繼承只增加世代，國號不變。
9. 天下震動會短期提高其他國家對第一名的圍剿意願。
10. 事件不是只有 LOG：會實際影響徵兵、金屬成本、農業、貿易、宣戰、結盟與 AI Action 權重。

【UI】
- 國家基本狀態新增：政權、戰略模式、政治穩定、戰爭疲勞。
- 外交戰績新增：近期事件。
- 國家總覽在政治穩定低於 20 且未戰爭時顯示「政危」。
