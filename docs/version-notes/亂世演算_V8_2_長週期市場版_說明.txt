《亂世演算》V8_2｜長週期市場版

【版本定位】
V8_2 是 V8_1 貨幣守恆修正版的長期經濟平衡更新。
不新增新的 RL Action，也不改 State 維度，因此不需要清空既有 Q-Table。

【一、世界銀行的金幣怎麼回到國家手裡？】

V8_1 已有「流動性穩定器」：
- 每 10 Turn 正常檢查一次。
- 流通率低於 72% 時立即檢查。
- 目標讓各國流通金幣約維持累計發行量的 82%。
- 每次最多動用當時世界銀行準備金的 50%。
- 世界銀行至少保留 5,000 金幣。
- 正常回灌只用既有準備金，不印新錢。

V8_2 保留以上規則，但改善分配方式：

舊：
低流動性 60% 國家，每國大致等額。

新：
仍先找「金幣 / 人口」最低的 60% 國家，
再按照各國人口規模分配回灌金幣。

因此超長局中：
10,000 人的大國不會和 100 人小國拿一樣多流動性。

這只是中央銀行的流動性調節。
富國真正變得更富，主要仍靠：
- 賣出資源
- 世界市場交易
- 聯盟援助
- 戰爭掠奪
而不是靠銀行補助。

【二、單筆掛單改為人口倍率】

V8_1 原本單筆掛單硬上限：180。

V8_2 改為：

單筆掛單上限 ≈ 人口 × 1.8

最低 180，極端安全上限 1,000,000。

例：
人口 100      -> 180
人口 500      -> 900
人口 1,000    -> 1,800
人口 5,000    -> 9,000
人口 10,000   -> 18,000
人口 50,000   -> 90,000
人口 100,000  -> 180,000

實際成交量仍會受到以下限制：
1. 買方有多少金幣
2. 賣方有多少庫存
3. AI 真正缺多少 / 多多少
4. 對手掛多少單
5. 買賣價格是否交叉

因此「人口大」只代表市場容量變大，
不代表可以憑空交易。

【三、有錢大國可以和有錢大國做大宗交易】

人口大的國家：
- 糧食、木材、金屬的目標庫存本來就會隨人口放大。
- 短缺與盈餘自然也會變大。
- 現在單筆掛單上限同步放大。
- 買方仍必須真的有足夠金幣。
- 賣方仍必須真的有足夠庫存。

因此長期跑到數千、上萬年後，
世界強國不會被「每次只能交易 180」卡住。

【四、貨幣守恆繼續保留】

基本恆等式：

各國持有金幣 + 世界銀行準備金 = 累計發行量

政策支出：
國家 -> 世界銀行

市場交易：
買方 -> 賣方

聯盟援助：
援助國 -> 受援國

世界銀行回灌：
世界銀行 -> 低流動性國家

亡國：
金幣移交勝方或世界銀行，不會憑空消失。

可直接看到各國隨人口變化後，目前最大單筆交易容量。
