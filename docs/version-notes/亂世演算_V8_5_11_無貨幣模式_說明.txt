亂世演算 V8_5_11｜無貨幣模式

主程式頂部：
MARKET_ECONOMY_ENABLED = False

False（本版預設）：
1. 停止市場掛單、撮合、成交、報價與三個市場交易 AI（交易方向、價格、數量）。
2. 停止世界銀行收費、回流、增發、懸賞金、冠軍金幣、政策物價指數與換幣。
3. 原有 Action 8 世界市場，以及聯盟子策略「優惠交易／資源交換」不會進入合法動作清單。
4. 既有存檔的金幣欄位保留但不參與國家經濟狀態、Reward 或決策；新局不發行金幣。
5. 原本需要金錢的基建、生育、增產、聲望修復及外交援助，改用該國當下糧食、木材、金屬各 10%。不足不會造成政策被金錢門檻鎖住；庫存為 0 的資源成本也是 0。
6. 外交援助的混合資源會轉給受援國；其他政策的混合資源則作為政策消耗。
7. 戰爭、結盟、圍剿、背叛、防禦、動員、產業配置、襲擾、裁軍及聯盟救援等非交易動作保留原本的兵力、外交、物資與情境條件，不會再受金幣條件阻擋。

True：恢復 V8_5_10 原有貨幣、市場、銀行、換幣與交易 AI。

注意：開關請在啟動遊戲前設定；執行中途修改檔案不會改變已載入程序。啟動後 LOG 會顯示目前使用的經濟模式。
