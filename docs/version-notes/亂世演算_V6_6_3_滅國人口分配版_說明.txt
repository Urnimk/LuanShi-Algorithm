《亂世演算》V6.6.3｜滅國人口分配版

【核心修正】

舊版國都陷落時：
- 先找勝方中現有士兵 / 戰力最高的國家。
- 所有生還人口全部交給該國。

V6.6.3 改為：

生還農民按照「本場戰爭各參戰國的累積出兵貢獻比例」分配。

例如：
甲國累積出兵貢獻：60,000
乙國累積出兵貢獻：30,000
丙國累積出兵貢獻：10,000

敵國滅亡後若有 1,000 名農民生還：

甲國：600 人
乙國：300 人
丙國：100 人

不再全部交給甲國。

【出兵貢獻如何計算】

1. 正式宣戰第一波實際 deployment 會記錄。
2. 持續戰爭每一回合，各國此戰線「有效兵力」也會累加。
3. 第二戰線原本只計 55% 有效兵力，因此貢獻也只計 55%，不會重複灌水。
4. 打到最後傷亡很多的盟國仍保留前面實際投入過的貢獻，不會因最後兵少就被抹掉。

這比單純看「滅國當下剩多少兵」更公平。

【整數人口分配】

使用最大餘數法，確保：
- 分配後總人口 = 實際生還人口
- 不會因小數四捨五入憑空多出 / 少掉人口

【主要攻城國】

仍保留一個「主要攻城國」處理：
- annexed_count
- capital_captures
- 35% 戰利資源
- 55% 房屋接收

但主要攻城國不再依「目前總戰力最大」判斷，
而是依本場戰爭的累積出兵貢獻最高者判斷。

【編年史滅國兇手】

如果是多國聯合作戰且有聯盟 / 戰爭陣營名稱，
編年史的「滅國兇手」優先顯示聯盟 / 陣營名稱。
單國戰爭則顯示主要攻城國。

【舊存檔相容】

舊的進行中戰爭沒有 attacker_troop_contribution 時：
1. 先用目前參戰國士兵數作為臨時比例。
2. 若所有參戰國都為 0，才平均分配。

新建立的戰爭會完整記錄累積出兵貢獻。

【其他功能保留】

- V6.6.2 編年史政權修正
- 滅國後重建政權
- 重建後首次交接恢復正統政權
- 左側國家詳細資訊 / 編年史切換
- 戰力權重投票
- SUCCESSION_MIN_TENURE = 5000
- SUCCESSION_CHANCE_PER_COUNTRY = 0.1
- 斷點續跑
- 世界局勢
- Q-table
