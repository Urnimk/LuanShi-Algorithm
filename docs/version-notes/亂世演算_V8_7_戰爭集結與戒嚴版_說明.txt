亂世演算 V8_7｜戰爭集結與戒嚴版

一、版本定位

本版修改戰爭時間流程與國家生存邏輯，屬於底層規則變動，因此依版本規則由 V8_6_3 升為 V8_7。
沒有新增 Action 編號，也沒有擴大 256 種戰略狀態上限。

二、戰爭集結與守方預警

- 宣戰後不再於同一年立刻造成傷亡。
- 進攻方需先集結 3～5 年，參數位於主程式頂部：
  WAR_MUSTER_YEARS_MIN = 3
  WAR_MUSTER_YEARS_MAX = 5
- 集結期間不計戰爭回合、不扣前線補給、不產生戰鬥傷亡。
- 防守方會立即收到「敵軍集結」警報，並顯示攻擊方及剩餘準備年數。
- 防守方可利用這段時間正常決策、徵兵、築城、調整產業或進入戒嚴。
- 集結完成後才進入原本的持續戰爭流程。

三、本屆後段前五名爭冠

- 本屆前段及中段仍提高前三名的決策機會。
- 本屆後段時，世界前五名每年保證取得一次主動決策機會。
- 前五名會進入既有「爭冠：有望／領先」狀態，並標示 championship_drive = 爭奪冠軍。
- 保證的是思考與行動機會；實際選擇發展、動員、外交或戰爭仍由 Q 值決定，沒有強迫宣戰。
- 參數：LATE_SEASON_CONTENDER_COUNT = 5。

四、低軍備戒嚴

平衡設計採「硬安全底線＋AI自由決策」：

- 士兵低於總人口 5% 時自動發布戒嚴。
- 戒嚴期間一般年度徵兵批次為原本的 4 倍。
- 農民與士兵的糧食維持費、士兵金屬維持費為 2 倍。
- 戒嚴徵兵仍受農民人數、糧食、金屬、軍民比例上限限制，不會憑空增加士兵。
- 士兵比例達 30% 才解除戒嚴，使用 5%／30% 雙門檻避免狀態反覆開關。
- 戒嚴不新增 Action；AI仍自主決定其他政策。低於5%屬亡國級危機，因此不等待 Q 值碰巧選到動員。

頂部參數：
MARTIAL_LAW_TRIGGER_SOLDIER_RATIO = 0.05
MARTIAL_LAW_RELEASE_SOLDIER_RATIO = 0.30
MARTIAL_LAW_RECRUIT_MULTIPLIER = 4.0
MARTIAL_LAW_UPKEEP_MULTIPLIER = 2.0

五、復名政變

- 國家若曾因政變改變國號，後續發生政變時有 25% 機會成為「復名政變」。
- 復名後恢復最初建立國家時的原始國名，政權類型為「復名政權」。
- 復名屬於政權更替，仍會增加國家總世代並寫入編年史。
- 參數：RESTORATION_COUP_CHANCE = 0.25。
- 只有實際抽中政變時才判斷復名，不是每年直接抽 25%，因此長期模擬中仍屬少見事件。

六、順帶修正

- 修正重建政權保護函式的回傳位置錯誤，避免部分攻擊保護判斷失效。

七、測試結果

- Python 語法與模組編譯：通過。
- 戒嚴觸發、加速徵兵、30%解除：通過。
- 集結期間零戰鬥回合、守方顯示倒數：通過。
- 復名政變恢復原始國號：通過。
- 固定 Seed 跑至 1,000 年：完成。
- 第 1,000 年存活 99 國，沒有負人口、負糧食、負木材、負金屬或負貨幣。
- 集結戰爭可正常轉入交戰；後段前五名均正確標示爭奪冠軍。
- 測試未出現 Traceback 或 ERROR。

八、觀察重點

1. 戒嚴國是否因 2 倍維持費陷入過度長期的資源危機。
2. 3～5 年預警是否讓守方有足夠時間補兵，但不至於讓進攻永遠失去突襲價值。
3. 後段前五名的行動頻率是否造成戰爭過密；若有，可降低 LATE_SEASON_CONTENDER_COUNT。
4. 復名政變屬低頻事件，需長期運行或提高 RESTORATION_COUP_CHANCE 才容易觀察。
